# Каталог материалов

Публичный статический каталог для GitHub Pages. Посетители могут искать и открывать материалы без регистрации. Карточки, опубликованные для всех, находятся в `materials.js`; доступ к их изменению определяется правами на репозиторий GitHub, а не интерфейсом сайта.

## Перед публикацией

`materials.js` пока содержит демонстрационные карточки без ссылок на реальные файлы. Замените их утвержденными материалами и проверьте, что описания и ссылки можно показывать всем в интернете. Сам репозиторий и GitHub Pages не подходят для хранения секретов и непубличных файлов.

## Локальный запуск

В этой папке запустите любой локальный HTTP-сервер, например:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация через GitHub Desktop

1. Войдите в GitHub Desktop под учетной записью GitHub.
2. Выберите `File` -> `Add local repository` и укажите **эту папку**. Локальный Git-репозиторий и первый коммит уже созданы. Не выбирайте родительскую папку `gj` или весь каталог `Codex`.
3. Проверьте список файлов и нажмите `Publish repository`. Для бесплатного GitHub Pages оставьте флажок `Keep this code private` выключенным: репозиторий должен быть публичным. Сайт будет общедоступным.
4. На GitHub откройте `Settings` -> `Pages`, выберите `Deploy from a branch`, ветку `main`, папку `/(root)` и сохраните.
5. После публикации GitHub покажет адрес вида `https://USERNAME.github.io/REPOSITORY/`. Проверьте поиск, фильтры и открытие карточек по этой ссылке.

## Кто может добавлять материалы

Посетители сайта не могут публиковать карточки. Владелец репозитория может пригласить доверенных редакторов через `Settings` -> `Collaborators` -> `Add people`. Редакторы с доступом на запись меняют `materials.js` в GitHub или через GitHub Desktop; после коммита и публикации обновления появляются у всех. Для обязательного согласования изменений настройте защиту ветки `main` с pull request и проверкой владельца.

Новая карточка — отдельный объект внутри массива `window.MATERIALS` в `materials.js`. Скопируйте соседний объект, задайте уникальный `id`, измените название, тип, продукт, назначение, формат, версию, описание и теги. Для кнопок в карточке укажите публично доступные `viewUrl` и/или `downloadUrl`; без них сайт покажет «Ссылки пока не добавлены». Проверьте права доступа к самим файлам отдельно: публичная ссылка на каталог не открывает закрытый файл Google Drive.

Карточки, созданные в старом прототипе, остаются в `localStorage` исходного браузера и помечены «Только в этом браузере». Они не попадают на GitHub автоматически; их данные нужно перенести в `materials.js` перед общим запуском.
